# Template 02 · Default alive or default dead?

> "Assuming their expenses remain constant and their revenue growth is what it has been over the last
> several months, do they make it to profitability on the money they have left?" [aord, Oct 2015]

PG credits Trevor Blackwell with a calculator for this [aord]. Below is a plain version you can do by hand
or in a spreadsheet. The arithmetic is standard; the question is his.

## Inputs

| Input | Value |
|---|---|
| Cash in the bank (B) | |
| Monthly expenses, assumed constant (E) | |
| Current monthly revenue (R) | |
| Monthly revenue growth over the last few months (g), e.g. 0.10 for 10% | |

## Month by month

Start with cash B. Each month: revenue = previous revenue × (1 + g); cash = cash + revenue − E.

| Month | Revenue | Cash at end of month |
|---|---|---|
| 1 | | |
| 2 | | |
| 3 | | |
| ... | | |

- **Default alive** if revenue reaches E (profitability) before cash reaches zero.
- **Default dead** if cash hits zero first.

## Then answer

1. Alive or dead? ______
2. If dead: how many months until cash runs out? ______. You're in the fatal pinch if growth is slow and
   there isn't time to fix it: "default dead + slow growth + not enough time to fix it." [aord]
3. Plan B, written down: what you'd cut, and the date you switch to it. [aord] ______
4. Are you counting on investors? Say it out loud: "We're default dead, but we're counting on investors to
   save us." [aord]
5. Any hires planned? "Hiring too fast is by far the biggest killer of startups that raise money." [aord]

If you're already in the pinch, his advice: "re-evaluate the probability of raising more money... the
probability is zero" and choose between shutting down, making more, or spending less. [pinch]
